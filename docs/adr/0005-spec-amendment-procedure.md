# ADR-0005: 规范修订程序

- 状态：已接受（2026-09-02）

## 决策

- fractal.md 是宪法，实现期间永不编辑。
- 一切澄清、缺口裁决、具体化进入 `spec/amendments.md`
  （编号 `AM-<set>-<n>`，含：修改对象、决策、理由）。
- 影响架构的选择（模块边界、外部依赖、存储格式）另立 `docs/adr/`。
- 修订流程（`spec-amend` 技能）：发现缺口 → 起草条目 → 落 ADR（若涉及架构）→
  更新 `spec/invariants.md`（若新增错误码）→ 测试先行落地 → 标记生效。
- 实现与规范冲突时禁止静默偏离；已生效修正案只能被后续修正案覆盖，不可删除。

## 后果

- 规范与实现双向可追溯：条款 ↔ AM ↔ ADR ↔ 代码 ↔ 测试。
- 宪法文本保持可发表、可引用的完整性。

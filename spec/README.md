# Spec System

fractal.md 是宪法：原语、定义、公理、定理。实现期间永不编辑。
实现过程对规范的澄清、缺口裁决、具体化全部落在本目录：

| 文件 | 职责 |
|---|---|
| `amendments.md` | 生效修正案（AM-xxx）：缺口裁决与具体化，与宪法共同构成有效规范 |
| `invariants.md` | 不变量目录：Guard 规则、错误码、REJECT 行为、恢复路径 |
| `glossary.md` | 规范记号 ↔ 代码符号 ↔ 文件位置的双向映射 |

修订程序见 `docs/adr/0005` 与 `spec-amend` 技能。修正案必须引用被修改/扩展的条款，
写明决策与理由，并在代码与测试落地后方可标记生效。
